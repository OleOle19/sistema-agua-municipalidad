# Manual operativo del sistema municipal

Este directorio contiene la fuente de verdad para construir el manual dirigido a
Caja, Ventanilla y Administración. El contenido explica tareas y decisiones de
uso; los detalles de instalación y mantenimiento se documentarán por separado
en el manual técnico.

## Alcance acordado

La primera edición cubrirá el selector municipal, Agua, Caja Municipal y la
supervisión administrativa de App Campo. Caja Luz se incluirá en los pasos de
cobranza que ya forman parte de Caja Municipal.

El módulo administrativo completo de Luz requiere un anexo independiente antes
de combinarse con este manual, porque aún conserva nombres históricos de roles
que no coinciden totalmente con los seis niveles mostrados por Agua y Caja.

## Regla de publicación

El manual visible dentro del sistema no mostrará contraseñas, variables de
entorno, direcciones internas, copias de seguridad ni datos reales de
contribuyentes. Las operaciones críticas llevarán una advertencia previa y solo
se explicarán en los capítulos correspondientes al rol autorizado.
