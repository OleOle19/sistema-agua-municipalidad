# Frontend municipal

Aplicación React que reúne los módulos de Agua, Energía y Caja Municipal. El selector inicial carga cada dominio de forma diferida y mantiene sus sesiones aisladas.

## Comandos

```bash
npm ci
npm run dev
npm run lint
npm run build
```

Las variables disponibles y sus valores de desarrollo están documentados en [`.env.example`](.env.example). Consulta el [README principal](../README.md) para conocer la arquitectura y la puesta en marcha completa.
